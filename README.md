# About-me

サイトURL：https://momiji25315.github.io/about-me/

このサイトは僕の好きな物を知ってもらうために制作しました。<br>
僕は今回、好きなゲームと好きなキャラクターと好きなラーメンについての<br>
３つのページと、お問い合わせページを制作しました。

# 課題の紹介

## TOP

-TOPページのこだわりポイントは、背景にアニメーションを追加する事で、<br>
動きを付けたことです。<br>
-自己紹介は簡単なもので良いなと思ったので、<br>
TOPページに生年月日と出身地を書きました。<br>

## お問い合わせ

-お問い合わせページは、全体的に文字を大きくする事で、<br>
文字を読みやすくしました。

## 好きなゲーム紹介

-好きなゲーム紹介ページは、紹介したいコンテンツを縦に並べ、<br>
下にスクロールする事で見れるようにしました。<br>
-また、コンテンツごとに背景の色を変更しました。

## 好きなラーメン紹介

-好きなラーメンページは、好きなゲーム紹介ページを参考にしたので、<br>
ほとんど同じです。<br>
-好きなゲームページと好きなラーメンページで差別化した所は、<br>
ラーメンページの方は、コンテンツごとの背景の色を統一した所です。

## 好きなキャラクター紹介

-好きなキャラクターページも好きなゲームページとほぼ同じで、<br>
背景の色をコンテンツごとに背景の色を変更しました。<br>
-好きなゲームページと差別化した所は、コンテンツの数が多かったため、<br>
1ページ目と2ページ目に分けた所です。

## 一番見てほしい所

-好きなキャラクターページのコンテンツごとの背景の色を、<br>
そのキャラクターのイメージカラーにした所です。

# 力を入れた点

## 実装面
-こだわった所は、写真が縮むのが嫌だったため、<br>あえて写真のサイズを固定した所です。

## デザイン面

-TOPページのアニメーションの入れ方をネットで調べて、<br>そのアニメーションの色を変え、適用しました。<br>
-アニメーションのコードをどこに入力するのかが、<br>いまいち分からず手こずりました。
